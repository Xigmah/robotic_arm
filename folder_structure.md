## Dependency Flow

```
┌─────────────────────────────────────────────────────────┐
│                      Application Layer                  │
│                   (examples/ folder)                    │
│                                                         │
│  User code that uses your library                      │
└────────────────────┬────────────────────────────────────┘
                     │
                     │ includes from
                     ▼
┌─────────────────────────────────────────────────────────┐
│                    Public API Layer                     │
│                   (include/arm/ folder)                 │
│                                                         │
│  Clean headers users #include                          │
└────────────────────┬────────────────────────────────────┘
                     │
                     │ implemented by
                     ▼
┌─────────────────────────────────────────────────────────┐
│                  Implementation Layer                   │
│                     (src/ folder)                       │
│                                                         │
│  .cpp files with actual logic                          │
└────────────────────┬────────────────────────────────────┘
                     │
                     │ tested by
                     ▼
┌─────────────────────────────────────────────────────────┐
│                      Test Layer                         │
│                    (tests/ folder)                      │
│                                                         │
│  Unit tests validate correctness                       │
└─────────────────────────────────────────────────────────┘
```

## Build Phases (suggested order)

```
Phase 1: Foundation
├── math/
│   ├── Vector3D       ← Start here (simple, testable)
│   └── Transform      ← Then this

Phase 2: Joint System
├── joints/
│   ├── Joint          ← Abstract base
│   └── RevoluteJoint  ← Concrete implementation

Phase 3: Kinematics
├── kinematics/
│   ├── ArmConfiguration  ← Define your 3-DOF arm
│   ├── KinematicChain    ← Forward kinematics
│   └── AnalyticIK        ← Inverse kinematics (3-DOF)

Phase 4: Commands
├── commands/
│   ├── ArmCommand          ← Base class
│   ├── JointSpaceCommand   ← Easiest to implement
│   └── CartesianCommand    ← Uses IK

Phase 5: Controller
└── ArmController  ← Ties everything together
```

## Module Isolation

```
Each folder is a module with minimal coupling:

math/
├─ No dependencies on other modules
└─ Pure math utilities

joints/
├─ Only depends on: math/
└─ No knowledge of kinematics or commands

kinematics/
├─ Depends on: joints/, math/
└─ No knowledge of commands or controller

commands/
├─ Depends on: kinematics/, joints/, math/
└─ No knowledge of controller

controller/
└─ Depends on: everything
   (but this is okay - it's the orchestrator)
```


## CMake Module Organization

```
CMakeLists.txt (root)
├─ Sets project name, C++ standard
├─ Add subdirectories
└─ Defines library target

src/CMakeLists.txt
└─ Collects all .cpp files into library

tests/CMakeLists.txt
└─ Links test executable against library
```
